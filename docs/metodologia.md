# Metodología

## 1. Identificación del problema

Se parte de necesidades operativas de mantenimiento y supervisión de instalaciones deportivas:
- dispersión de información;
- seguimiento manual;
- dificultad para consolidar incidencias;
- necesidad de históricos;
- control de parámetros;
- elaboración periódica de informes.

## 2. Traducción a requisitos funcionales

Los requisitos se agrupan en:
- inventario;
- sensores;
- mantenimiento;
- incidencias;
- checklist;
- consumos;
- KPIs;
- informes.

## 3. Diseño de datos

Se diseña un modelo relacional orientado a:
- trazabilidad;
- normalización;
- explotación analítica;
- crecimiento posterior.

## 4. MVP

El MVP prioriza:
- representación funcional;
- datos sintéticos;
- navegación;
- indicadores;
- demostración de viabilidad.

## 5. Separación entre demostrador y producción

### Demostrador
- datos sintéticos;
- arquitectura conceptual;
- código de ejemplo;
- consultas SQL de muestra.

### Producción
Requeriría, entre otros:
- integración con sistemas reales;
- seguridad;
- usuarios y permisos;
- copias de seguridad;
- monitorización;
- pruebas;
- despliegue;
- gobierno del dato.

## 6. Principio de publicación

El repositorio público expone únicamente material suficiente para acreditar competencias técnicas sin publicar información sensible o productiva.
